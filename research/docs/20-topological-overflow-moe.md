# Polaris 架构研究：纯整数无参 MoE 路由与拓扑防拥堵

## 一、 痛点：传统 MoE 的算力消耗与路由坍塌
混合专家系统（MoE）是目前大模型扩展参数的重要方向。但传统基于 Softmax 的门控网络（Router）存在两大痛点：
1. 计算开销大：每个 Token 都要与专家矩阵进行浮点乘法。
2. 极易发生路由坍塌（Routing Collapse）：大量 Token 挤向少数专家，导致负载严重失衡，必须依赖复杂的负载均衡损失函数（Load Balancing Loss）来强行纠偏。

## 二、 解决方案：拓扑查表与物理溢出
本文基于 Polaris 引擎的三维空间拓扑，提出一种“无参 MoE 路由机制”：
1. **特征哈希**：将高维浮点特征通过方差与符号计算，直接映射到三维网格坐标 (1, 3, 5)。
2. **查表分配**：若坐标命中预设的 11 个“5”节点（专家），则直接分配，无任何矩阵乘法。
3. **拓扑溢出**：若目标专家已达容量上限，系统根据曼哈顿距离，直接将 Token 沿最近的拓扑通道平移溢出。

## 三、 结论
该架构彻底摒弃了浮点门控网络，通过物理容量与拓扑距离，天然实现了完美的负载均衡。在长序列推理中，能极大降低算力消耗，且绝对免疫“路由坍塌”现象。
