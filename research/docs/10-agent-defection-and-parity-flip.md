# Polaris 架构研究：多智能体系统的防叛变机制与奇偶破局

## 一、 引言：AI 集群的“安史之乱”
在大规模多智能体（MARL）集群中，智能体在探索时容易脱离全局共识，走向极端的特征发散（即“叛变”）。传统的做法是强制重置（杀死智能体），这损失了多样性与计算资源。本文基于“先后天逆元”与“宇称翻转”，提出了一种极低成本的防叛变机制。

## 二、 逆元收权：先软后硬的控制论
1. **推恩令（乘3/乘7）**：当检测到智能体在边界表面发散时，首先调用模10乘法逆元算子，试图通过代数旋转剥离其极端特征。
2. **偶数死锁陷阱**：研究发现，仅靠乘3或乘7，处于偶数域（2,4,6,8）的叛变状态会陷入“奇偶守恒”死循环，无法自行跳出。
3. **帝5巡查（+5宇称翻转）**：若逆元收权失败，系统果断注入 `+5` 算子，强行打破奇偶守恒，将状态从偶数域暴击到奇数安全域（1,3,7）。

## 三、 工程价值
这种“先软后硬”的策略实现了最低算力的平滑对齐。这为大模型分布式安全（Distributed Safety）提供了一套极简的纯整数护城河。
