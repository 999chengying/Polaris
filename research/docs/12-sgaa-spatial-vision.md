# Polaris 架构研究：球面梯度自适应注意力 (SGAA)

## 一、 痛点：传统局部窗口的“一刀切”
现代 Transformer 在处理长文本时，往往采用固定大小的局部注意力窗口。这导致核心节点浪费算力，边缘节点容易变成信息孤岛。

## 二、 SGAA 的核心机制
本文提出一种拓扑变焦镜头（Spatial Vision）。系统根据 Query 所在的球壳半径（R²=4, 8, 12），动态分配它的注意力“拓扑曼哈顿距离限制”。
- **面心节点（内圈）**：采用高聚焦，只看身边（半径限制3）。
- **棱心节点（中圈）**：采用中广角（半径限制5）。
- **顶点节点（外圈）**：采用全息广角，强制让外围节点监控全局（半径限制9）。

## 三、 工程意义
不依赖任何浮点计算，仅靠纯整数距离比对生成 0/1 掩码。不仅极大幅度降低了注意力矩阵的稠密度，还赋予了外围 Token “监控全局”的生物学视觉特征。
