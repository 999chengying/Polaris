# Polaris 架构研究：基于拓扑阶段的动态算力分配模型

## 一、 引言：打破“全量算力”的暴政
在传统的 Transformer 推理中，无论模型是在生成一句简单的“你好”，还是在推导复杂的物理公式，其底层计算图都是一样的——每一层都要经过全量的浮点注意力矩阵（Global Attention）。这导致了极大的算力浪费。
本文基于前文的“拓扑阶段监控器”，提出一种**“按需分配”的动态算力调度器**。利用纯整数状态在八卦轨道上的位置，系统能瞬间判断当前任务的难度，动态调整计算资源。

## 二、 动态调度机制

系统根据所处的四个拓扑阶段，实施差异化的计算策略：
1. **阶段一（浅层游走，状态如 2→3→1→4）**：
   - **算力分配**：10%
   - **策略**：纯整数查表、简单的局部路由（或直接走小参数模型）。不触发全局浮点 Attention。
2. **阶段二（跨面跃迁，状态如 4→5→9）**：
   - **算力分配**：50%
   - **策略**：过渡模式，激活局部专家层（MoE），准备进行重度计算。
3. **阶段三（深度推演，状态如 9→7→6→8）**：
   - **算力分配**：100%
   - **策略**：满算力模式。全量唤醒 GPU 集群，进行高精度的浮点 Attention 与长程记忆检索。
4. **阶段四（面心回落，状态如 8→5→2）**：
   - **算力分配**：20%
   - **策略**：降维模式。释放 KV Cache，清空无用缓存，准备下一次输出。

## 三、 实验数据与战果

我们在包含 11 个状态步的典型推演周期内进行了模拟：
- **静态全局 Attention 总需求**：12.0 单位。
- **动态分配总需求**：4.8 单位。
- **最终战果**：在确保模型深度思考（阶段三获得满额算力）的前提下，**整体算力节省高达 60%！**

## 四、 对国产大模型与异构计算的重大意义
1. **CPU/GPU 异构协同**：在阶段一和阶段四，完全可以使用低功耗的纯整数 NPU 或 CPU 查表完成；仅在阶段三调用 GPU。极大缓解了显存压力。
2. **无参训练的 MoE**：传统混合专家系统（MoE）需要训练一个 Gating Network。而本调度器无需训练任何参数，完全靠离散拓扑的位置规则，就实现了完美的算力门控。
3. **致敬“元亨利贞”**：元（发散起步）→亨（跨越通达）→利（深度斩获）→贞（回落固本）。东方的系统周期律，完美契合了最前沿的 AI 调度需求。

## 五、 结论
本文提出的动态算力分配模型证明：计算与记忆的解耦，不需要依赖更复杂的神经网络，只需要我们在离散拓扑的路由上给出合理的规则。这为下一代绿色 AI、极低功耗大模型的落地，指明了一条纯整数演化的新路径。
