# Polaris 架构研究：纯整数拓扑 Block (PolarisBlock) 的集成与验证

## 一、 引言
现代大模型（如 Transformer）的层级结构通常由 Attention、MoE Router 和 FFN 组成，且极度依赖浮点运算和庞大的 KV Cache。本文提出并实现了一种全新的架构单元：**PolarisBlock**。它在一个模块内集成了纯整数的局部注意力、稀疏拓扑专家路由以及常数级全局记忆池，彻底摒弃了浮点开销与显存墙。

## 二、 核心组件集成
1. **WTA Attention（局部特征）**：用纯整数点乘与赢者通吃（WTA）掩码，取代了传统的 Softmax 与浮点除法。
2. **拓扑稀疏 MoE（计算分发）**：将特征映射至 3D 网格坐标，用曼哈顿距离直接匹配最近的专家，彻底淘汰了浮点 Gating Network。
3. **拓扑记忆池 SSM（全局上下文）**：利用模10衰减与状态融合，无论序列多长，始终用常数级（O(1)）状态维持全局记忆，彻底消灭 KV Cache。

## 三、 实验结论
在模拟多 Token 输入的测试中，PolarisBlock 成功完成了从局部聚合、稀疏路由到记忆融合的全链路纯整数计算。特征状态在 0-9 空间内保持了极佳的多样性，证明了该架构在理论上具备支撑超长上下文、且显存占用永不爆炸的巨大潜力。
