# RFC: 关于将 Polaris PTPP 纯整数防幻觉网关接入大模型推理层的技术提案

**致：DeepSeek / 智谱 / 阿里通义 等国产大模型研发团队**
**发起人：999chengying / Polaris Project**

## 一、 痛点与现状
当前 LLM 面临长尾幻觉问题，传统方案（如 RLHF、重采样、外挂 RAG）成本极高。尤其是当模型在进行复杂逻辑推理时，其隐空间特征的方差会剧烈发散，最终导致输出偏离事实。如果能在推理层（Inference Layer）建立一个“特征级”的物理拦截机制，将极大提升模型的可靠度。

## 二、 解决方案：PTPP 纯整数拓扑投影协议
PTPP 是一种**即插即用**的轻量级推理侧护栏，它不会修改大模型的任何权重参数。

1. **特征接收**：接收模型输出层的 Hidden States（例如 4096 维浮点向量）。
2. **拓扑投影**：通过哈希方差降维，瞬间将浮点降维为纯整数三元组 (d1, d2, d3)，算力消耗可忽略不计。
3. **因果干预**：若特征落入危险发散区，系统根据拓扑偏移定则（Value + Address），计算出一个极小的代数偏置，将其反向叠加至原 Hidden States 中。

## 三、 核心指标
- **极低延迟**：单次诊断与干预耗时 0.05ms（基于 CPU 即可实现）。
- **零训练**：完全无需重新训练，不需要人类反馈。
- **防过度纠正**：拓扑映射是保守的，只在特征击穿极值时才触发，不影响正常生成的多样性。
