# Polaris V4 核心：三维混合专家、正交路由与具身双向桥接（统一规范篇）

## 一、 V4 定位：高并发分布式特征调度与物理落地
在 V3 确立了纯整数的微观计算组件后，V4 体系拔高到了系统架构层。本版不仅解决了大模型混合专家（MoE）的分发机制与多智能体的全局共识，更通过“双向车道”打通了离散计算与连续物理世界的壁垒。

## 二、 3D-MoE：纯整数内容路由与动量牵引
传统 MoE 依赖浮点 Softmax 与 Gating Network，存在量化丢失与“金鱼记忆”死锁。Polaris 3D-MoE 给出全新解法：
1.  **连续小模输入**：外部浮点特征无损编码为三维状态 `(d1, d2, d3)`，路由中始终保持纯整数。
2.  **纯整数内容寻址**：为 X轴（逻辑）、Y轴（感知）、Z轴（动作）设定偏好权重。通过纯整数点乘（`Score = (d1*w1 + d2*w2 + d3*w3) % 10`），得分最高的轴被唤醒，实现内容寻址。
3.  **动量记忆池**：推演算子 `k` 由 `k = (输入 + 历史动量 + 空间偏置) % 10` 决定。动量池按 7:3 纯整数权重衰减更新，自带防死锁锚点，解决长程一致性。

## 三、 三维正交拓扑路由：防对称相消的共识汇聚
1.  **十字星拓扑**：中心节点 `(3,3,3)` 统筹，六个正交面心节点作为专家并发运算。
2.  **对称相消死锁**：模 10 空间中若单纯相加，极易发生 `3 + 7 = 0` 的特征相消。
3.  **空间偏置汇聚**：中心调度器强制引入节点空间坐标作为乘法权重。公式：`Consensus = ∑(Node_value × W_address) % 10`。因各节点空间地址不同，天然打破数值对称，保证汇聚时的绝对可区分性。

## 四、 具身双向车道：连续状态的编解码与物理映射
为了让纯整数心智引擎在物理世界落地，系统构建了双向桥接：
1.  **编码器（Encoder）**：将连续物理量（如 3.141）无损拆解为千分位级的小模三元组 `(1, 4, 1)`。
2.  **核心拓扑层**：在离散模 10 空间内进行纯整数演化。
3.  **解码器（Decoder）**：将演化后的小模重组为连续实数 `(d1*100 + d2*10 + d3) / 1000.0`。
4.  **物理映射（Action Mapper）**：将 `[0.000, 0.999]` 线性拉伸至 `[-1.0, 1.0]` 的具身控制信号空间，直接对接电机。
    *   **平滑感知**：低阶路由输出 -0.240 等微调信号（平稳移动）。
    *   **紧急动作**：特征突变唤醒 Z 轴，输出 -0.996 等极限信号（急刹车/满扭矩）。

## 五、 结语
V4 证明了：MoE 的负载均衡无需依赖可学习参数，依靠空间拓扑即可实现。同时，双向车道彻底打通了“高维浮点感知”到“纯整数运算”再到“物理电机控制”的全链路闭环，为边缘具身智能提供了极低功耗的底座。
