# Polaris 工程规范与资源清单

## 一、 系统集成测试与鲁棒性验证清单
摒弃传统浮点神经网络通过“Loss 曲线”盲猜模型状态的做法，每次迭代需通过以下离散代数测试：
### 1. 基础算术与状态机
- [ ] **进位级联**：验证 `(0,0,9)+1` 触发中宫状态机并输出 `(0,1,0)`。
- [ ] **边界翻转**：验证绝对零点 `(0,0,0)-1` 坍缩至 `(9,9,9)`。
- [ ] **逆元对称**：验证模10空间下乘3后再乘7，状态100%无损耗还原。
### 2. 拓扑路由与防幻觉
- [ ] **对称死锁**：输入 `(8,3)` 与 `(2,7)`，验证拓扑偏移（值+址）成功打破相消。
- [ ] **过平滑防御**：TokamakConv层输入全同质化特征（方差0），验证触发相变算子拉开差异。
- [ ] **极限环侦测**：模拟持续相同状态，验证元观测者能否预警并强制归中（重置为5）。
### 3. 大模型端到端闭环
- [ ] **PTPP投影**：向网关注入发散的浮点幻觉特征，验证能否校准回 `[7,8,9]`。
- [ ] **受限生成**：输入指令，验证解码器严格遵守语法模板，杜绝语无伦次。

## 二、 核心资源与模块依赖映射
本引擎剥离了浮点张量框架，纯整数与离散代数构建，**零硬依赖**（不依赖 PyTorch，可直译 C/Verilog 跑在 FPGA 上）。
- `v2_arithmetic.py`：四则运算、状态机进位与模10群演化。
- `v3_tokamak.py`：双墙约束、图卷积与降维相变。
- `v4_moe_router.py`：分布式路由、空间偏置与三维并发。
- `v5_ptpp_gateway.py`：大模型浮点投影、因果干预与元观测者。
- `v6_llm_decoder.py`：纯整数词表采样、受限语法状态机。
