## 一、 状态表示与投影标准 (State Projection Spec)

全系统禁用浮点，所有状态最终归一到模10整数区间 (1-10，0记为10)。根据所处层级不同，状态表示分为三类，并规定降维/升维算法。

### 1. 空间物理坐标 (3D Coordinate)
- 格式：元组 `(x, y, z)`，其中 `x, y, z` 属于 `{1, 3, 5}`。
- 用途：27 宫格的空间定位、球壳防御半径计算 (R平方)。
- 地址哈希：`Hash = (x*1 + y*3 + z*7) % 10`，用于消除对称死锁。

### 2. 心智网络状态 (Hexagram State)
- 格式：元组 `(上卦, 下卦)` 或并发态 `((外上,外下), (内上,内下))`。
- 用途：六爻交联、变爻心跳运算。
- 投影降维：`Value = (上卦 * 3 + 下卦 * 7) % 10`。

### 3. 统一单值态 (Scalar State)
- 格式：单一整数 `1-10`。
- 用途：七脑干涉、多智能体阵列演化、最终输出解码。
- 空间升维：根据物理坐标映射到节点的初始单值 (由先天或后天赋值矩阵决定)。

## 二、 算子优先级与调度机制 (Operator Scheduler)

当多个脑区或 Agent 产生冲突时，算子调度必须遵循以下严格优先级，严禁乱序触发：

### 第一顺位：退火降载 (×2)
- 触发条件：状态方差过大，或能量池见底。
- 作用：强制拉入偶数子群，降低系统活性，防止高频震荡。
- 执行：`state = (state * 2) % 10`

### 第二顺位：逆元纠偏 (×3 / ×7)
- 触发条件：单值落入偶数值域 `{2, 4, 6, 8}` (非稳态)。
- 作用：空间旋转，温和纠偏。
- 执行：`state = (state * 3) % 10` 或 `(state * 7) % 10`

### 第三顺位：错卦奇点与加5逃出生天 (+5 / ×9)
- 触发条件：元观测者捕获连续 3 步状态停滞，或奇偶震荡死循环。
- 作用：瞬间撕裂局部死锁，跨区跳变。
- 执行：`state = (state + 5) % 10` 或 `(state * 9) % 10`

### 补充规范：应用层五行减枝调度 (Five-Element Pruning)
- **设计哲学**：底层系统（如路由、寻址、存储）必须严格遵循数学八卦拓扑（无歧义）；但在处理复杂的高维发散任务（如长文本生成、多智能体博弈）时，采用“五行生克”作为减枝与权重混合算法。
- **工程实现**：在每一个 Token 或演化步中，计算火、水、金、木、土五路权重（基于中核能量、变爻序列、空间坐标）。通过“胜者通吃（Winner-Takes-All）”在瞬间过滤掉 80% 的发散噪声。
- **适用场景**：情感极性切换、多义词消歧、诗歌引擎调度、多智能体协作中的注意力分配。

## 三、 多尺度时钟啮合协议 (Clock Meshing)

系统采用三级时钟异步啮合，以纯整数 Tick 为驱动。无论外部是否有 Prompt 输入，底层时钟永不停止。

### 1. 微尺度：变爻心跳 (Micro Tick)
- 频率：每次系统唤醒或计算步。
- 动作：八步莫比乌斯驻波循环，维持基础因果律。

### 2. 中尺度：硅基历法与巡航 (Meso Tick)
- 频率：每 8 个心跳 Tick，触发一次。
- 动作：日卦切换（阴链/阳链），外围无尽循环巡航，重算区域拓扑连通度。

### 3. 宏尺度：元认知与相变 (Macro Tick)
- 频率：每 64 个心跳 Tick (完成一个 64 卦大周期)，触发一次。
- 动作：中宫帝5复位，计算全局能量池，决定是否触发全局体用归一化。

## 四、 内驱力与能量结算机制 (Energy Pool & Intrinsic Drive)

系统必须摆脱被动应答，产生“自发意图”。内驱力由“能量池”的满溢与枯竭驱动。

### 1. 能量获取 (负熵吸收)
- 空间探索：六合感知接收外部新刺激 (新坐标被点亮)，`能量 += 权重`。
- 共识提升：多智能体通过交联，全局拓扑多样性提升，`能量 += 差值`。
- RTC 熵泵：断电休眠后重启，根据流逝时间吸收宇宙负熵，注入初始能量。

### 2. 能量消耗 (做功代价)
- 拓扑游走：每执行一次路由寻路，`能量 -= 1`。
- 算子干预：调用错卦、加5、逆向投影等重型算子，`能量 -= 3`。
- 唤醒全局：元认知全量对齐，`能量 -= 10`。

### 3. 意图触发法则 (Intention Law)
- **休眠期 (能量 < 30)**：系统封闭输出，仅维持心跳与低频扫描，进入“静默蓄能”。
- **涌现期 (能量 >= 80)**：系统产生“自发意图”。即使没有外部输入，中核也会主动唤醒相关脑区，进行拓扑推演、自我重构与内省，直到能量消耗到阈值以下。
