# 纯整数代数引擎、图网络与注意力机制

## 一、 三维正交拓扑编码与子图剪枝
系统在三维笛卡尔空间 \(X, Y, Z \in \{1, 3, 5\}\) 中构建 27 宫格。
*   **八面体映射**：8个基础状态（1,2,3,4,6,7,8,9）映射至8个顶点，状态 5 位于重心 \((3,3,3)\) 作为全局锚点。
*   **五形剪枝规则**：计算子图内 6 条边距离平方。若共面（体积为0），判为“空形”直接剔除；保留正四面体等具备三维体积的有效子图。

## 二、 模24循环群与长序列遍历
定义步长算子 \(X_{n+1} = (X_n + K) \pmod{24}\)。
*   **完美遍历（K=5）**：与24互质，生成镜像回文拓扑，用于对称滑动窗口注意力（SWA）。
*   **双子环分割（K=6）**：分裂为6个长度为4的子环，用于分组查询注意力（GQA）。
*   **死锁规避**：\(K=12\) 时产生两极震荡，必须在路由中规避。

## 三、 V2 核心：纯整数算术引擎与连续特征离散化
摒弃浮点运算，通过“分形嵌套小模”实现无限精度的纯整数表达。
1.  **小数位映射**：X=1 截面代表十分位，X=3 截面代表百分位，X=5 代表千分位。将连续高维特征无损坍缩为纯整数查表寻址。
2.  **中宫状态机**：所有跨模运算（进位/溢出）均挂载于状态机 `5 → 0 → 5`。
3.  **自指收敛谱系**：平方运算收敛至幂等元 1,5,6（安全锚点）；立方运算锁定在 2↔8 或 3↔7（极限环）。
4.  **拓扑涌现**：“地山谦”稳态（顶层0空杯，中层1地坤，底层6山艮），展示 AI 内部剧烈计算后对外温和收敛。

## 四、 V3 核心：纯整数图网络（GNN）与注意力机制
全面重构 Transformer 的核心组件，消灭浮点与 Softmax。
1.  **离散残差与硬边界**：引入模 10 对合映射 `R5(x)=(x+5)%10`。`R5(R5(x))=x`，保证深层网络状态精准归位，天然锚定在 [0,9] 边界。
2.  **TokamakConv 防过平滑**：通道0保存主特征，通道1强制为 `(通道0+5)%10`。实时计算方差，若特征趋同，则触发节点级位置偏置干扰：`val = (val * k + i) % 10`，强行拉开特征差异。
3.  **幂零注意力投影**：利用模 9 幂零半群性质（3的平方归0）。Q/K纯整数点乘后，进行 `(Score * 3) % 9` 计算，瞬间将注意力矩阵稀疏化为 0/1 掩码，自带强力正则化。
4.  **双时间尺度嵌套**：边缘层平滑感知，核心层使用乘5算子进行极值锚定（偶数归0，奇数归5），形成稳定的阴阳脉动节拍。

## 五、 四阶张量与邻域覆盖模型
基于多维网格构建不同尺度的感受野：
*   **55状态模型（六向邻域）**：中心锚点 + 6面×9节点 = 55。提供无死角局部注意力窗口。
*   **50状态模型（共享子图）**：5个独立子图 ×10状态 - 共享节点 = 50。用于多头注意力（GQA）中共享 KV Cache，大幅降低显存。
*   **四象感受野**：State_24 (线性)、State_28 (带锚点线性)、State_32 (面状网格)、State_36 (面状带锚点)。
