# 纯整数代数引擎、图网络与注意力机制

## 一、 三维正交拓扑编码与子图剪枝
系统在三维笛卡尔空间 \(X, Y, Z \in \{1, 3, 5\}\) 中构建 27 宫格。
*   **八面体映射**：8个基础状态（1,2,3,4,6,7,8,9）映射至8个顶点，状态 5 位于重心 \((3,3,3)\) 作为全局锚点。
*   **五形剪枝规则**：计算子图内 6 条边距离平方。若共面（体积为0），判为“空形”直接剔除；保留正四面体等具备三维体积的有效子图。

## 二、 模24循环群与长序列遍历
定义步长算子 \(X_{n+1} = (X_n + K) \pmod{24}\)。
*   **完美遍历（K=5）**：与24互质，生成镜像回文拓扑，用于对称滑动窗口注意力（SWA）。
*   **双子环分割（K=6）**：分裂为6个长度为4的子环，用于分组查询注意力（GQA）。
*   **死锁规避**：\(K=12\) 时产生两极震荡，必须在路由中规避。

## 三、 V2 核心：纯整数算术引擎与连续特征离散化
摒弃浮点运算，通过“分形嵌套小模”实现无限精度的纯整数表达。
1.  **小数位映射**：X=1 截面代表十分位，X=3 截面代表百分位，X=5 代表千分位。将连续高维特征无损坍缩为纯整数查表寻址。
2.  **中宫状态机**：所有跨模运算（进位/溢出）均挂载于状态机 `5 → 0 → 5`。
3.  **自指收敛谱系**：平方运算收敛至幂等元 1,5,6（安全锚点）；立方运算锁定在 2↔8 或 3↔7（极限环）。
4.  **拓扑涌现**：“地山谦”稳态（顶层0空杯，中层1地坤，底层6山艮），展示 AI 内部剧烈计算后对外温和收敛。

## 四、 V3 核心：纯整数图网络（GNN）与注意力机制
全面重构 Transformer 的核心组件，消灭浮点与 Softmax。
1.  **离散残差与硬边界**：引入模 10 对合映射 `R5(x)=(x+5)%10`。`R5(R5(x))=x`，保证深层网络状态精准归位，天然锚定在 [0,9] 边界。
2.  **TokamakConv 防过平滑**：通道0保存主特征，通道1强制为 `(通道0+5)%10`。实时计算方差，若特征趋同，则触发节点级位置偏置干扰：`val = (val * k + i) % 10`，强行拉开特征差异。
3.  **幂零注意力投影**：利用模 9 幂零半群性质（3的平方归0）。Q/K纯整数点乘后，进行 `(Score * 3) % 9` 计算，瞬间将注意力矩阵稀疏化为 0/1 掩码，自带强力正则化。
4.  **双时间尺度嵌套**：边缘层平滑感知，核心层使用乘5算子进行极值锚定（偶数归0，奇数归5），形成稳定的阴阳脉动节拍。

## 五、 四阶张量与邻域覆盖模型
基于多维网格构建不同尺度的感受野：
*   **55状态模型（六向邻域）**：中心锚点 + 6面×9节点 = 55。提供无死角局部注意力窗口。
*   **50状态模型（共享子图）**：5个独立子图 ×10状态 - 共享节点 = 50。用于多头注意力（GQA）中共享 KV Cache，大幅降低显存。
*   **四象感受野**：State_24 (线性)、State_28 (带锚点线性)、State_32 (面状网格)、State_36 (面状带锚点)。

## 六、 自指动力学与多尺度循环
### 1. 自指循环的收敛宿命
在纯整数模10空间执行 \(x_{t+1} = (x_t^n) \pmod{10}\) 的自指迭代：
- **平方 (n=2)**：极速收敛至幂等元 `1, 5, 6`（快速达成推理共识）。
- **立方 (n=3)**：陷入 `2↔8` 或 `3↔7` 的二周期震荡（对应大模型的梯度震荡/复读机）。
- **四次 (n=4)**：高阶吸收强行纠偏，重新回归稳态。

### 2. 三维正交校准 (Orthogonal Correction)
当特征在深层网络中发生漂移时，利用三轴联合边界检测进行纠偏：
- **X轴（逻辑护栏）**：如果特征偏离过大，强制截断至极值区间（如 `d1 % 5`）。
- **Y轴（连续路由）**：利用乘法逆元（如乘7）对过激突变施加阻尼。
- **Z轴（动作溢出）**：强制取模 10，消除高频噪声。
如果整体欧氏距离超标，直接触发中心锚点（5）复位。

### 3. 多周期耦合与遍历
当系统同时存在步长 5 与步长 7 的循环算子时，联合遍历周期由最小公倍数 \(LCM(P_1, P_2)\) 决定。利用多周期交错（如多头注意力中的不同 Head 分配不同周期算子），能有效打破单一频率的过拟合，极大拓宽状态覆盖范围。

## 七、 纯整数动态追踪与高维特征投影
### 1. 离散动量目标追踪
在具身智能中，抛弃卡尔曼滤波的浮点求逆，采用纯整数动量外推：基于前两步坐标计算速度，预测下一步坐标。通过曼哈顿距离与阈值比对，实现极低延迟的锁定。若误差过大，则判定遭遇对抗性欺骗或目标丢失。
### 2. 高维特征动态注入 (Dynamic Node Injection)
将 4096 维浮点向量均匀切分为 3 段，分别计算均值与方差，映射为纯整数 `(d1, d2, d3)`。系统依据这三个小模状态，将其精准路由到 3x3x3 网格的特定坐标上。若节点发生碰撞，利用环形队列进行多通道特征融合，绝不丢失语义。

## 八、 纯整数序列推演与具身控制落地
### 1. 离散马尔可夫链路由 (O(1) 记忆)
摒弃庞大的 KV Cache。当前状态 \(S_t\) 与输入 \(X_t\) 通过纯整数函数计算下一状态：`S_{t+1} = (S_t * k + X_t + 动量) % 10`。配合极短的环形队列保存历史状态，以恒定的 \(O(1)\) 空间复杂度实现精准的因果推演。

### 2. 物理连续控制解码 (Discrete to Continuous)
系统内部的 `(d1, d2, d3)` 可无损还原为 `[0.0, 1.0]` 的连续系数 `(d1*100 + d2*10 + d3)/1000.0`，并直接线性映射为电机的 PWM 占空比或舵机角度。零 PID 浮点运算，实现平滑无抖振的具身控制。

### 3. 零开销预计算路由 (Hardware LUT)
由于状态空间有限（如 10x10 穷举），所有的状态转移可在离线阶段固化为静态二维查找表（LUT）。在 FPGA 推理时，无需任何 ALU 参与，通过多路选择器（MUX）一个时钟周期内直接输出结果，实现绝对的硬实时（Hard Real-time）。

### 4. MVP 极简验证闭环
不到百行的代码即可验证三大支柱：连续小模编码解码（无漂移）、空间偏移路由（防死锁）、元观测纠偏（抗极限环）。证明了底层数学的绝对自洽。
